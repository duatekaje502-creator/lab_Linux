📚 Panduan Perintah Ubuntu
💡 Tips Belajar: Klik pada salah satu kartu perintah di bawah ini untuk langsung mencobanya di terminal, atau ketik tutor untuk panduan latihan!
1. Navigasi & Direktori
pwd Klik Uji
Print Working Directory — Menampilkan lokasi folder Anda saat ini.
ls -la Klik Uji
List — Melihat semua isi folder beserta hak akses dan detailnya.
cd Documents Klik Uji
Change Directory — Masuk ke dalam folder Documents. Gunakan cd .. untuk kembali.
2. Membuat & Mengelola File
mkdir belajar_linux Klik Uji
Make Directory — Membuat folder baru bernama belajar_linux.
touch catatan_baru.txt Klik Uji
Membuat file kosong baru bernama catatan_baru.txt.
echo "Halo Ubuntu!" > catatan_baru.txt Klik Uji
Menulis teks ke dalam file menggunakan operator redirect (>).
